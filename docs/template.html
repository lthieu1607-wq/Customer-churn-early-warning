Which signals carry the model

Permutation importance: AUC lost when the feature is shuffled

Only three behaviors matter. App logins, failed payments, tickets and satisfaction add almost nothing once those are known. A 3-feature model scores AUC 0.775.

Declining usage: change in average transaction amount

Churn rate by Jan–Sep amount change bucket

U-shaped. A drop of 48% or more doubles churn risk to 50%; a surge of 44% or more also raises it, to 29%.

Shift in withdrawal share

Churn rate by change in share of transactions that are withdrawals (percentage points)

Stable or slightly rising withdrawal share is the safest pattern (7.5–12%). Large moves either way push churn to 30–37%.

This tab runs a 3-feature version of the model so it can work in the browser. Its predictions were exported from the trained scikit-learn forest on a grid of input values, so the numbers are the model's own. The full 62-feature model behind the Action Center scores reaches AUC 0.745 out-of-fold; the 3-driver model scores 0.772, which shows the extra 59 features were mostly noise.

Limits. The dataset has no revenue field, so customer lifetime value stands in for revenue. Expected value at risk is inflated for the largest accounts: the model predicts 12.3% churn for the top CLV decile, which actually churned at 4.9%.
